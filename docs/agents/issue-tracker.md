# Issue tracker: GitHub

TAL issues and specs live in rammohanrediee/TAL GitHub Issues. Use `gh` from this repository to create, read, list, label, comment on, and close issues.

PRs as a request surface: no.

When a skill says to publish a ticket, create a GitHub issue. When it says to fetch a ticket, read that issue and its comments. Record blocking relationships with GitHub issue dependencies where available; otherwise put `Blocked by: #...` in the issue body. Work on unblocked tickets first.
